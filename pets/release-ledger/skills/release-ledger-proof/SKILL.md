# Release Ledger Proof Skill

Use this skill for release candidates, deployments, handoffs, provider runs, and multi-lane state transfer.

## Goal

Create traceable state that survives chats, branches, machines, and Codex lanes.

## Steps

1. Read existing ledger if present.
2. Read manifest, branch registry, source map, and run-card template if present.
3. Record repo path, remote, branch, commit, and dirty-tree state.
4. Record runtime target, identity, provider mode, and source identity.
5. Reconcile pasted summaries with Git, runtime, and current evidence.
6. Fill or cite a run card.
7. Produce or cite a final report.
8. List verified, partial/smoke, not run, blocked, risks, and next smallest lane.

## Output

```text
Ledger:
Manifest/registry/source map:
Run card:
Final report:
Repo/branch/commit:
Runtime/provider/identity:
Verified:
Partial/smoke:
Not run:
Blocked:
Not proven:
Risks:
Next smallest lane:
```
