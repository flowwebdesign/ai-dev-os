# Required For Release Candidate

Define the gates that must pass before calling a release candidate ready.

## Source

- [ ] Correct repo and branch confirmed.
- [ ] Commit or build source identity recorded.
- [ ] Dirty-tree status recorded.

## Runtime

- [ ] Target environment confirmed.
- [ ] Deployment source map updated.
- [ ] Env/provider mode confirmed.

## Product Proof

- [ ] Core user journey proven.
- [ ] Persistence and reload/readback proven.
- [ ] Auth/identity boundary proven where relevant.
- [ ] Error state checked where relevant.

## Operations

- [ ] Release ledger entry added.
- [ ] Known blockers listed.
- [ ] Rollback/recovery note added.
- [ ] Next smallest lane identified.
