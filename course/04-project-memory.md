# Project Memory

Project memory should route agents, not drown them.

The AI memory index is loaded first. It points to deeper files only when the task needs them.

Mistakes prevented:

- loading huge stale handoffs
- missing active runtime changes
- repeating old failure patterns

Exercise: fill out `.ai-dev/AI_MEMORY_INDEX.md` for a project in under 80 lines.

Client offer angle: package memory indexes as part of project onboarding.
