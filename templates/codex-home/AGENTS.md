# Global Codex Rules

Before work, identify repo path, remote, branch, worktree, dirty state, runtime target, identity/auth state for writes, provider/cost mode for paid calls, exact scope, and stop condition.

When `.ai-dev/AI_MEMORY_INDEX.md` exists, read it first.

Load the index first. Load deeper files only when the task classifier, proof requirement, or active risk points to them.

Classify the task before editing. Map proof before claiming success.

Stale chats, handoffs, screenshots, and summaries are pointers, not truth when Git, runtime, API, database, browser, or deployment evidence disagrees.

Stop on wrong repo, wrong branch, unknown runtime, unknown provider/cost mode, missing proof boundary, destructive action without approval, or missing release traceability when release-relevant.

Final reports separate proven facts, assumptions, skipped checks, risks, changed files, checks run, and next smallest action.
