# Universal Start Prompt

Start by proving current truth before implementation.

Required:

1. Confirm repo path, remote, branch, and dirty-tree state.
2. Read `.ai-dev/PROJECT_CONTEXT.md`, `.ai-dev/PROJECT_RULES.md`, `.ai-dev/ACTIVE_STATE.md`, and `.ai-dev/PROOF_REQUIREMENTS.md` if present.
3. Classify the task using `core/TASK_CLASSIFIER.md`.
4. Name runtime target, identity/auth state, provider/cost mode, exact scope, and stop condition.
5. Only then inspect the smallest relevant files and proceed.

Final report must separate verified, partial/smoke only, not run, blocked, changed files, checks run, risks, and next smallest lane.
