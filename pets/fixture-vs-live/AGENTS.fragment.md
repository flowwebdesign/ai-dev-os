# Fixture vs Live Fragment

Before provider or data-source claims, prove the mode.

Required behavior:

- Name mode: fixture, live, auto, mock provider, real provider, or unknown.
- Resolve `auto` before claiming either fixture or live.
- Name provider, cost flags, budget, cache policy, and ledger/run-card location.
- Record call evidence without exposing secrets.
- Verify persisted output and readback when claiming behavior.

Stop if mode, provider, budget, or ledger requirements are missing.
