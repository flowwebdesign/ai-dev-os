# Agent Roles

Roles keep work bounded.

Explorer finds context. Worker changes code. Reviewer looks for risk. Proof checker tests claims. Scribe writes handoffs.

Mistakes prevented:

- one agent mixing investigation, edits, review, and release claims without boundaries
- missing independent review of risky changes
