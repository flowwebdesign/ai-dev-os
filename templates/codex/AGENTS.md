# Codex Project Instructions

Use this file as a project-level `AGENTS.md` starter.

## Lane Start

Before code changes, run compact checks for:

- current path
- git status
- branch
- remote
- target runtime
- identity/auth state for writes
- provider/cost mode for paid calls
- exact scope and stop condition

Read `.ai-dev/PROJECT_CONTEXT.md`, `.ai-dev/PROJECT_RULES.md`, `.ai-dev/ACTIVE_STATE.md`, and `.ai-dev/PROOF_REQUIREMENTS.md` before non-trivial work.

## Work Protocol

- Preserve user work.
- Inspect the smallest relevant files.
- Make one safe change.
- Run the smallest relevant proof.
- Record verified, partial, not run, and blocked.

## Final Response

Include changed files, tests/checks run, risks, and next smallest lane. Do not claim success beyond current proof.
