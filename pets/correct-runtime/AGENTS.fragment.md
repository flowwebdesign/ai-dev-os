# Correct Runtime Fragment

Before testing or claiming runtime behavior, prove the target.

Required behavior:

- Confirm repo path, branch, commit, and dirty-tree state.
- Name runtime target and URL or port.
- Confirm the running process or deployment source when possible.
- Confirm identity/auth state before writes.
- State Linux, Windows, WSL, or server constraints that affect proof.
- Prefer repo-relative checks; do not hardcode personal paths.

Stop when the runtime cannot be attached to the source and claim.
