# Done Means Verified Fragment

Before saying work is done, map each claim to evidence.

Required behavior:

- Classify the lane before verification.
- Run the smallest relevant check for the actual change.
- Distinguish documentation-only readback, unit tests, build/typecheck, browser proof, provider proof, extension proof, and release proof.
- Include a `Not Proven` section when verification is incomplete.
- Use proof labels: `verified`, `partial`, `smoke`, `not_run`, `blocked`.

Never report broad success from narrow evidence.
