# Learning Log - 2026-07-06

## What Changed

- Converted the repo from a documentation scaffold toward a usable control layer.
- Added token-light memory index templates.
- Added a Codex home bootstrap with conservative claims about uncertain integration points.
- Added practical hooks, project-management templates, a minimal MCP starter, and check scripts.
- Added and proved a usable `ai-dev-os` CLI with `init`, `attach`, `check`, `doctor`, `version`, and `help`.
- Proved the profile matrix across minimal, standard, serious, and serious detect modes.
- Separated global install from project init on Windows and Bash installers so `-InstallCodexHome` and `--install-codex-home` no longer create source-repo `.ai-dev` files.

## Mistakes Prevented

- Reading too much stale context before current truth.
- Claiming hooks or skills auto-load without local proof.
- Treating MCP as a source of truth instead of a compact project-state interface.
- Assuming one profile smoke test proves the whole profile system.
- Treating parsed flags as working features without reading generated project state back.
- Letting a global installer mutate the current project directory without an explicit project-init flag.
